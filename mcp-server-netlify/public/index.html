MCP Server

This site is a Netlify-hosted MCP endpoint. Use the API routes below instead of browsing the root page.

  • /health - health check
  • /api/discovery - discovery metadata
  • /api/auth/create or /api/subscribe - create account
  • /api/auth/refresh - refresh JWT token
  • /api/mcp - MCP tool execution

If you still see 404, please make sure the Netlify deploy was built after this change.
